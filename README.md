# Computer Vision Midterm Studio

A static preparation site based on the supplied course lectures and assigned chapters.

- 450 questions: 219 multiple choice, 164 calculations, and 67 written questions, with answers and explanations.
- 34 study units covering Szeliski Chapters 1–3, Trask Chapters 1–5, and CV Lectures 2–5.
- 8 interactive models and 5 complete mock exams, including the supplied sample.
- Downloadable notes and exam answer keys.

To publish with GitHub Pages, use the main branch and the repository root. `.nojekyll` serves the files directly. All asset paths are relative, so the quiz works under a repository URL.

Open `index.html` locally to practice, or serve this directory with any static HTTP server. Progress is saved in the current browser. Written answers are self-assessed against model answers.

The study material is preparation, not an official answer key for a future exam. The original sample’s testing instructions describe the actual exam conditions.
